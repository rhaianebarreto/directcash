CREATOR IA CLUB

Seu DirectCA$H,
pelo navegador.

Instale pelo celular ou computador, sem abrir o terminal. Sua instalação mantém seus dados na sua Cloudflare.

1. Prepare suas contas

Você precisa de uma conta na Cloudflare e no GitHub. O GitHub guarda sua cópia do aplicativo; a Cloudflare mantém o painel funcionando.

Use seu navegador habitual. Se uma tela externa ficar difícil de usar no celular, ative a opção “Versão para computador” do navegador.

2. Guarde seu acesso

Você usará dois valores na instalação. O botão abaixo cria valores aleatórios neste navegador. Copie ambos para seu gerenciador de senhas antes de continuar. Eles não são enviados por esta página nem salvos automaticamente.

Guarde a chave APP_KEY: ela protege a conexão com a Meta. Não a troque após conectar seu Instagram.

3. Instale na sua Cloudflare

O link de instalação ainda está sendo preparado pelo Creator IA Club. Solicite à equipe o link publicado antes de continuar.

Instalar meu DirectCA$H →
  1. Autorize GitHub e Cloudflare quando solicitado.
  2. Escolha um nome para sua instalação. Se você já instalou, use a opção Atualizar na central.
  3. Nos campos ADMIN_PASSWORD e APP_KEY, cole os valores que você guardou acima.
  4. Mantenha a criação automática do banco e o comando de publicação npm run deploy. Não habilite planos pagos.
  5. Confirme e aguarde a conclusão. Abra o endereço workers.dev apresentado pela Cloudflare.

O aplicativo prepara as tabelas durante a publicação. Não é necessário copiar SQL.

4. Conecte e ative

Entre no seu painel com a senha que guardou. Em Configuração, siga o guia da Meta para conectar seu Instagram. Cole a licença recebida do Club e crie uma automação para testar.

Seu perfil será vinculado automaticamente à licença. Perfis adicionais dependem das condições da sua licença.

Prefere instalar pelo Windows?

Extraia o kit recebido e abra INSTALAR-WINDOWS.cmd. Pressione Enter para iniciar, escolha um nome e autorize a Cloudflare. O instalador prepara o banco, gera o acesso e tenta abrir seu painel ao terminar.

Se o navegador não abrir, use o arquivo ABRIR-MEU-PAINEL.html criado na pasta. Guarde a senha exibida no instalador.

O sistema continua funcionando com o computador desligado. Os limites dos planos Cloudflare se aplicam; a instalação não contrata planos pagos.
